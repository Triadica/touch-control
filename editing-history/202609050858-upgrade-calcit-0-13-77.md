# 2026-09-05 08:58 Upgrade to Calcit 0.13.77

## English

- Align the Calcit compiler and `@calcit/procs` exactly at 0.13.77 while preserving touch-control 0.0.18 and its public control-loop behavior.
- Migrate strict Option and JavaScript-number boundaries exposed by the newer checker, using explicit safe defaults for fixed two-coordinate state.
- Replace legacy `get` calls on the `%element` Struct with typed field access and give the DOM renderer a nominal input contract. A production-browser run caught this runtime-only incompatibility after compile/build had passed.
