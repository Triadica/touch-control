# 2026-09-05 08:58 Upgrade to Calcit 0.13.77

## English

- Align the Calcit compiler and `@calcit/procs` exactly at 0.13.77 while preserving touch-control 0.0.18 and its public control-loop behavior.
- Migrate strict Option and JavaScript-number boundaries exposed by the newer checker, using explicit safe defaults for fixed two-coordinate state.
- Replace legacy `get` calls on the `%element` Struct with typed field access and give the DOM renderer a nominal input contract. A production-browser run caught this runtime-only incompatibility after compile/build had passed.
- Add a definition-attached coordinate-difference unit test. The production browser smoke renders one control, two hand pads and four circle buttons, exercises pointer clicks, updates the visible state loop, and reports no errors from the rebuilt bundle.
- Add reproducible quality/toolchain gates and immutable workflow action revisions.
- Keep deployment restricted to authorized pushes to `main`; pull requests run validation without exercising the rsync action or deployment secret.
- Disable setup-node's automatic package-manager cache discovery so the clean runner cannot invoke global Yarn 1 before Corepack activates the declared Yarn 4.12.0.
- Authenticate the production SSH host with a reviewed repository-pinned ED25519 key. The explicit rsync step fails closed with strict host checking and no longer inherits the former action's `StrictHostKeyChecking=no` behavior.

## 中文

- 新增坐标差分 definition test；production 浏览器 smoke 验证一个 control、两个 hand pad、四个 circle button、pointer click 与可见状态循环，重建 bundle 无错误。

- 关闭 setup-node 自动 package-manager cache 探测，避免干净 runner 在 Corepack 激活 Yarn 4.12.0 之前调用全局 Yarn 1。
- 使用仓库中经审阅固定的 ED25519 公钥认证生产 SSH 主机；显式 rsync 步骤开启严格 host checking 并以失败关闭，不再继承原 action 的 `StrictHostKeyChecking=no` 行为。
